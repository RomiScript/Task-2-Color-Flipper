🎨 Color Flipper — Gradient Generator

This the second task of my "12 labors of Hercules" Front-End challenge.
A simple and aesthetic gradient generator built with HTML, CSS and JavaScript.
Click the button to generate a random two-color gradient and instantly update the background.



🚀 Features

Generates random hex colors

Creates a smooth left-to-right gradient

Displays the current color code

Soft glass-morphism UI with animations

Fully responsive & beginner friendly

💡 How it Works

When the user clicks the Generate button

JavaScript creates two random hex colors

The background updates with a linear-gradient()

The hex code appears in the UI

Simple, aesthetic, satisfying ✨
